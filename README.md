## Objective

The objective of this project is to analyze retail customer and order data using Python, pandas, and SQL.

## Three key Findings

1. Corporate customers generated the highest total sales

2. Nairobi generated the highest regional sales.

3. Data quality issues affected the analysis, like data duplicate and missing data
